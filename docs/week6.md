#### What to do in the lab

First, read the Assignment **Task** description below. Then proceed to read this section.

The following electronic prototyping problems are intended to get you familiar with working with electronics so you can ask questions during lab and prepare yourself to complete the Task on your own. These are not graded, so if you're already comfortable with these concepts you are welcome to skip these in part or in full.


To succeed on the assignment task, your goal during the lab should be to design several electronic circuits in the Falstad simulator, build them physically, and inspect them using a multimeter. *You should also familiarize yourself with soldering*{: .text-red-300}. For all the problems below, simulate them in falstad first, then build them and check key currents/voltages with a multimeter
1. Build a circuit with a voltage source, and a single LED and resistor in series. The Maximum current tolerated by our LEDs is 20mA, and Forward Voltages are: Red/Yellow 2.0-2.2V; Blue/Green/White 3.0-3.2V. Choose resistances accordingly
1. Replace the series resistor with another resistor value that dims the single LED.
1. Using a pushbutton, build a circuit to enable lighting the LED when the button is pressed.
1. *Using a pushbutton, build a circuit to enable lighting the LED when the button is NOT pressed.*{: .text-red-300 }
1. Remove the push button. Using a potentiometer, build a circuit to enable manually dimming/brightening the LED. You must ensure that the max LED current is never exceeded, no matter what value is set by the pot.
1. Using a new circuit, make 3 LEDs light up with the same brightness.
1. Using a new circuit, make 3 LEDs light up with different brightnesses. 
1. *Using a transistor, build a circuit to enable lighting an LED when a button is pressed.*{: .text-red-300 }
1. *Using a transistor, build a circuit to enable turning on a DC motor when a button is pressed. How do you reverse the direction of the motor?*{: .text-red-300 }
1. *Ensure you complete solder training if you need, then continue to the task assignment*{: .text-red-300 }

### Task: Analog electronic device

#### Task definition

By Analog electronic device, we mean an electronic circuit that uses only analog components (as opposed to digital signals produced by a microcontroller) and is integrated into a fabricated enclosure.

To put this in context of what we've done before, think of it as building a computer mouse - but this time we're building both the enclosure and the electronics from scratch.
