# Mechanism Kit

This page details the assembly instructions for the mechanisms in the Mechanism Kit. Use the media below to assemble each mechanism one by one. With the exception of the timing belt, all the parts consituting each mechanism are strictly 3D printed or laser-cut. This exercise is intended to help you understand how you can design, build, and assemble your own mechanisms using only 3D printing and laser cutting with no extraneous parts. 


### Mechanisms

The kit will allow you to assemble the following mechanisms:
- **Spur Gears:** Transmit rotary motion between adjacent shafts, reversing direction and changing speed according to the gear ratio.
- **Geneva Drive:** Converts continuous rotary motion into intermittent, indexed rotation with pauses between steps.
- **Belt Drive:** Transmits rotary motion between separated shafts, with the speed ratio determined by the pulley diameters.
- **Scotch Yoke:** Converts continuous rotary motion into sinusoidal, reciprocating linear motion.
- **Cam and Follower:** Converts rotary motion into reciprocating linear motion determined by the cam profile.
- **Strandbeest:** Uses 4-bar linkages to convert continuous rotary motion into coordinated linkage motion that produces a walking trajectory; explore the motion using the [DIY Walkers Strandbeest Optimizer](https://www.diywalkers.com/strandbeest-optimizer-for-lego.html).
