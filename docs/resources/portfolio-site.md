# Portfolio Website

You will create a personal portfolio website for this class. This will host all of your assignments. Weekly assignments will be considered submitted once you have published your latest assignment documentation to your website. Only work that is documented on the personal website will be considered for grading.

Thorough documentation on your personal page is required in order to earn full credit for assignments. A well-documented assignment is one that provides sufficient information for someone else to understand - or ideally, fully replicate - your project. At a minimum this requires screenshots from software work (eg CAD), photographs of physical artifacts (fabricated parts and finished assemblies), and a thorough written description of the steps taken. An excellent page may also require code snippets, gifs, movies and/or links to outside resources.
