Machine setup and tests

Press each limit switch by hand: its label must change to pressed. If Home drives an axis away from its switch, press Stop, flip that axis and Home again. The test square should measure 100 mm per side. Unlock lets you jog and use the pen without homing (Draw still needs Home).       Machine settings built into the pen firmware (nothing to paste)
      

      
Built into the class firmware (grbl_pen), so there is nothing to paste. Only the four with a note are worth changing: $3 is set by the Flip buttons, $31 is the pen-up position of the servo, $130 and $131 are the machine area (a move beyond it is refused): the page sets them from Machine area under More settings when it connects. To change $31, type it in a sender app's console, e.g. $31=35. Pen down is not a setting: it is the Pen down value (S) in More settings, sent as M3 S70. Keep pins A0, A1 and A2 empty: GRBL uses them as Reset, Pause and Start.

      
$100 and $101 = 40 steps/mm for 1/8 microstepping (M0 + M1 jumpers), 200-step motors and 20-tooth GT2 pulleys; 80 for 1/16, 5 for full step. Axis backwards: $3=1 flips X, $3=2 flips Y, $3=3 both. Homing and limits are off, so the switches are ignored. Keep A0, A1 and A2 empty (Reset, Pause, Start); the joystick on A4, A5 and D12 can stay.
